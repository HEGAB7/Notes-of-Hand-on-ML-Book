# Hands-On Machine Learning with Arabic Explanation

### شرح كتاب Hands-On Machine Learning بالعربي

Arabic video tutorials and Jupyter notebook summaries for every chapter of **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow** (2nd Edition) by Aurélien Géron. This repo is the companion to my [YouTube playlist](https://www.youtube.com/playlist?list=PLrGq9NbP4ut6EPRzgV8gIc84Az329uQ8W) where I explain each chapter in detail in Arabic.

---

## Who Is This For?

- Anyone reading the book and looking for an Arabic explanation
- Students and developers getting into machine learning and deep learning
- Self-learners who prefer watching videos instead of reading 

## About the Book

Aurélien Géron's *Hands-On Machine Learning* is one of the most popular practical ML books. It covers classical ML with Scikit-Learn in Part I, and deep learning with Keras and TensorFlow in Part II. This repo follows the **2nd Edition** — a PyTorch edition may be added later.

---


## How to Use

1. Clone the repo: `git clone https://github.com/HEGAB7/Notes-of-Hand-on-ML-Book.git`
2. Watch the [video](https://www.youtube.com/playlist?list=PLrGq9NbP4ut6EPRzgV8gIc84Az329uQ8W) for the chapter
3. Open the corresponding notebook to review the key concepts and code
4. Try modifying the code and experimenting on your own

You can run the notebooks locally with [Anaconda](https://www.anaconda.com/) or directly in [Google Colab](https://colab.research.google.com/).
